Procurement & Deployment

Request guided pilot access to the self-hosted fair-outcomes evidence appliance for regulated credit decisions. For AWS customers, the intended guided-pilot path is AMI-first, with container/VM deployment available for private, controlled, or non-AWS paths where agreed.

Deployment steps

1

Request guided pilot access

Public AWS Marketplace access is not yet available. Contact Equilens to request controlled guided-pilot access to the AMI-first AWS path or agreed private deployment materials.

2

Prepare your environment

We will confirm the approved deployment path for your environment. Select instance type, region, VPC, and subnet per your change controls.

3

Boot the appliance

Boot runs docker-compose via systemd. The appliance listens on port 8080 (configurable), with optional Prometheus on 9090.

4

Run a test

Upload sample data or a sandbox dataset. Produce the PDF report, evidence manifest (SHA-256), and checksum log.

5

Confirm pilot scope

If evaluation fit is confirmed, we can align pilot terms or a Private Offer for enterprise rollouts.

Procurement package

Evidence bundle

  • Evidence manifest (JSON) and PDF report with embedded hashes.
  • Infrastructure BOM and network diagram (request access).
  • Control mapping aligned to FCA, EU AI Act, and ECOA checkpoints.

Current controlled-pilot product reference: v5.0.0-rc8.4. Public demo materials are selected synthetic/demo assets from that pinned release, including the demo report; supporting run packs and intake diagnostics are linked from FL-BSA documentation. They are not customer output, legal advice, or proof of a public Marketplace launch.

Commercials

  • Commercial terms are finalized during qualification; annual, multi-year, and Marketplace structures are post-qualification options where supported by the release path.
  • Pilot evaluations are scoped with agreed duration and success criteria.
  • Private Offer support for custom terms or multi-entity rollouts.

Deployment options

Guided AWS AMI-first

Primary current AWS customer path for controlled guided pilot or private handoff. Single-tenant AMI with deterministic boot, reporting services, and integration with customer IAM.

Container / VM deployment

Available for private, controlled, or non-AWS deployments where agreed. docker-compose stack (API, Worker, Redis); CPU-only profile available, with GPU preferred for faster synthetic generation.

Coordinate CSP, HSTS, and CAA updates through your network and DNS teams. We provide implementation runbooks on request.
